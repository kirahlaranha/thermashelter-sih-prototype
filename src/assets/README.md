# Assets

The prototype keeps all visual assets local. The landing hero terrain, beacon, shelter installation, technical grid, compass context and solar-direction cue are generated procedurally with Three.js / React Three Fiber; there are no runtime terrain or map downloads.

`india-natural-earth.svg` is a compact local locator outline simplified from the public-domain Natural Earth 1:110m Admin 0 Countries India feature. It is used only for geographic context around the Leh reference site.

Charts and the Configuration shelter diagram remain locally rendered SVG/CSS components.
